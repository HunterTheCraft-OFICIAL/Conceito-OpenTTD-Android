# 📖 Glossário de Termos Técnicos

Este glossário contém a padronização de termos técnicos em Inglês ↔ Português utilizados no projeto de tradução conceitual do OpenTTD.

## 📌 Como Usar Este Glossário

- **Termo em Inglês**: O termo original do código-fonte
- **Tradução Recomendada**: Como deve ser traduzido na documentação
- **Notas**: Contexto adicional ou observações importantes

## 📝 Termos que NÃO devem ser traduzidos

Alguns termos devem ser mantidos em inglês por serem:
- Nomes próprios de classes/funções
- Padrões da indústria de programação
- Termos universalmente reconhecidos

### Exemplos:

| Termo | Motivo |
|-------|--------|
| `enum`, `struct`, `class` | Palavras-chave de programação |
| `namespace`, `template` | Conceitos de C++ |
| `callback` | Padrão de programação |
| `GUI` | Sigla universal |
| `NewGRF` | Nome próprio do sistema de mods |
| `OpenTTD` | Nome do projeto |
